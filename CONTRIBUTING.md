# Contributing

Thanks for helping. A few rules keep the project legally safe:

1. **License of contributions.** By submitting a contribution, you agree that it
   is your own work, and that it is licensed under this project's license. You
   also grant the maintainer (kreanimator) a perpetual, irrevocable right to
   relicense your contribution, including under other licenses, as part of this
   project.
2. **No copyrighted test material.** Do not add questions, cue cards, transcripts
   or audio from published IELTS books or tests. Use original questions only.
3. **Permissive dependencies only.** New libraries and models must have a
   license allowed by [THIRD_PARTY.md](THIRD_PARTY.md). Add them to that file
   in the same pull request.
4. **No network calls** except downloading model weights from their official
   sources.
5. **Keep the code simple and readable.**
